Aplicação React.js para listagem de usuários consumindo a API JSONPlaceholder.

## Funcionalidades

- ✔ Listagem de usuários (nome, e-mail e telefone formatado)
- ✔ Campo de pesquisa por nome
- ✔ Modal com detalhes completos
- ✔ Design responsivo (3 colunas desktop → 2 tablet → 1 mobile)
- ✔ Formatação automática de telefones

## Pré-requisitos

- Node.js (v16+)
- npm (v8+)

## Instalação

1. Clone o projeto:

```bash
git clone https://github.com/PadilhaaUser/ProvaTecnica-UserHUB.git
cd ProvaTecnica-UserHUB

2. Instale as dependências (incluindo Axios):
npm install axios

3. Inicie a aplicação:
npm run dev
